About

Physics, firmware and a soldering iron

Wyrá means “bird” in Tupi, the Indigenous language behind many of Brazil's bird names.

The studio is run by Sergio Levy, a physicist with a BSc and MSc, now a PhD candidate in condensed matter physics at the Federal University of Ceará. He has spent years writing C, C++ and Python for simulations, machine learning and microcontrollers.

Each project started from a real need: getting a mixing desk onto a livestream, keeping an eye on a server room's air conditioning, a gift that needed a little magic. The code for all of them is on GitHub.
