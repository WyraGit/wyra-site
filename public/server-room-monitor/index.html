Server Room Monitor

A climate and power monitor built for the server room of the Physics Department at the Federal University of Ceará (UFC). It watches temperature, humidity and the air-conditioning load, and reports everything over MQTT.

  • 9 × temperature + humidity
  • 3 × AC current
  • MQTT + JSON
  • Arduino Mega 2560
Need something like this? View the source

What it does

Every sensor, around the clock

Climate across the room

Nine DHT11 sensors spread over the room report temperature and humidity. The monitor averages them and leaves out any sensor that fails a reading, so one bad cable doesn't skew the result.

Air-conditioning load

Three clamp-on current sensors (SCT-013) measure what each air conditioner draws, so you can tell at a glance whether a unit has stopped working.

Data you can use anywhere

Readings go out as JSON over MQTT on separate topics for temperature, humidity and current, ready for Home Assistant or any dashboard that speaks MQTT.

Status on the wall

A 20 × 4 LCD rotates through network status, the time (synced over NTP) and the latest readings, so you can check the room without a computer.
