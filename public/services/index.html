FAQ

Before you write

Who owns the code?

You do. The code written for your project is yours to use, change and sell. If it builds on code Wyrá already had, such as the Audio Hub firmware, you get a license to use that part in your product.

Do you need my hardware?

Usually not. The work is done on a development board with the same chip and parts, and you run the result on yours. If your hardware is unusual, we talk it through before you pay anything.

What if my project is bigger than one sprint?

It's split into sprints, each with its own scope and price. You can stop after any of them and keep everything delivered so far.

Which tools do you use?

The Arduino framework on ESP32 (classic and C3) and AVR boards such as the Mega 2560, and C++ and Python for desktop tools and data analysis. Code is delivered in a Git repository.
